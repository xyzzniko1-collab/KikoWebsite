📋 Ketentuan (Order · Speed Up · Refill) — wajib baca ▼

Order

  • Input link sesuai format di keterangan — pesanan tidak bisa dibatalkan.
  • Jangan pakai 2 layanan sekaligus untuk link yang sama (tunggu completed dulu).
  • Link salah / di-private / dihapus setelah order → otomatis completed, tanpa refund.
  • Status partial / canceled → saldo otomatis di-refund, bisa order ulang.
  • Jumlah maks = kapasitas total per akun/link, bukan per sekali order.
  • Speed & drop rate = estimasi, bisa berubah tergantung server. Report setelah 24 jam.

Speed Up

  • Untuk order stuck >24 jam (kecuali layanan bertanda SLOW).
  • Lapor Order ID ke CS; diproses 1×24 jam; maks 1×/hari per order.

Refill (garansi isi ulang drop)

  • Untuk drop >30% setelah status SELESAI (partial tidak bisa refill).
  • Hanya layanan bergaransi refill (lihat keterangan). Pakai tombol Refill di riwayat.
  • Akun harus PUBLIK & tidak ganti username — kalau tidak, refill gagal.
  • Jangan order ulang ke link sama selama proses (garansi hangus). Proses 3–5 hari.
  • Klaim tidak berlaku bila masa garansi sudah habis.
